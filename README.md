# 雅思阅读 / 听力考点词 · 网页版

把两本雅思词汇 PDF（《剑桥雅思阅读考点词真经》538 词表、《剑桥雅思听力考点词真经》179 词表）整理成**可直接在浏览器里用的词表**：去掉了原 PDF 里的公众号水印、LOGO 和二维码，重新排版为表格与卡片，并为每个同义替换词补了中文释义、为每个词条补了中英例句。

直接用浏览器打开 `index.html` 即可，无需安装任何东西、不联网也完全可用。

## 功能

- **搜索**：中英文都能搜，单词、词义、同义替换、例句全文匹配；按 `/` 聚焦，`Esc` 清空。
- **默写模式**（表格版 + 例句版）：一键隐藏全部中文，只留英文，适合自测；再点一下全部恢复。表格版会连分类说明一起藏起，但只隐藏文字、不收起列宽，行高和列位都不动，方便对着空白回想。
- **分项隐藏**：词义、替换词释义、例句译文可分别隐藏；表格版也有「隐藏词义 / 隐藏替换释义」两个开关。
- **状态记忆**：开关状态存在 localStorage，下次打开还是你上次的设置。
- **生词本**：四份词表里每条右侧都有 ☆，点一下收进同一本生词本（阅读 538 与听力 179 共用，便于把「考点词 + 同义替换」一起复习）。生词本页支持搜索、按来源/字母排序、导出 TXT、备份与导入 JSON。
- **背诵（逐词自测）**：每页右下角的「背诵这一页」是独立功能，跟生词本分开算。词卡一个一个跳出来，单词下面常显**纯英文例句**（表格版和例句版都有），先靠例句猜意思；点卡片（或空格）对答案，**释义 + 例句译文 + 同义替换 / 衍生词**一起出现。「不认识」就自动收进生词本并 10 分钟后重来，「认识」按 1→2→4→8→15→30→90 天往后推。538 和 179 各背各的，进度分别记录；「只背到期」可只过今天该复习的词。桌面端 `空格` / `1` / `2` / `Esc` 即可操作。弹层不受「默写模式」影响，开不开隐藏中文都能正常看答案。揭晓答案后，释义下方会显示**这个词背过几次**——「记住 3 次 · 没记住 1 次」，第一次见则提示「第一次见这个词」；顶部信息栏同时给出本次的「记住 n · 没记住 m」。生词本列表里每个词也带同样的记录标签（如「记住 3 · 忘 1」）。
- **遗忘曲线复习**：生词本按 `1·2·4·8·15·30·90` 天排期，答对升级、答错退回并 10 分钟后重来，连续答对 7 次记为「已掌握」。
- **拼写听写**：生词本里切到「拼写」模式，看中文释义（和同义替换）写英文，逐字判对错并显示正确拼写。
- **朗读**：单词和例句都能点小喇叭朗读（浏览器自带语音，优先英式发音）。
- **学习统计**：生词本页顶部有连续打卡天数、今日复习、今日新增、掌握率，以及近 14 天复习量柱状图。
- **语境短文（`段落.html`）**：把 538 的 376 个考点词和 179 的 179 个考点词全部写进 39 篇三五句的小短文（按词群/语义聚成一篇，句子刻意写短），**逐句中英对照**。词表里的词在短文里自动加粗高亮，不用手工标；点任意高亮词弹出释义 + **同义替换**，可以直接收进生词本。四个开关：`中译`（隐藏全部中文，只看英文）、`盲读`（英文模糊成灰条，点某句才揭开）、`遮挡`（先把高亮词藏起来，检查自己认不认得出）、`朗读`（从当前句开始逐句英音连播，读到哪句哪句高亮）。每章顶部实时显示「本章 176 词 · 短文里用到了 176 个（100%）」，点开还能看到没被用到的词。读到哪一章会记住，下次打开接着上次那章；也支持 `段落.html?ch=4` 直接跳组。每篇底部有「背诵本篇」，把这一篇的考点词直接拉进背诵窗口——和表格版、生词本共用同一份进度（`kd-rec`），认识的按遗忘曲线排期，不认识的自动进生词本；顶部「背诵本组」一次过完本组全部词。
- **打印友好**：`Cmd/Ctrl + P` 直接打印成纸质词表，不会带出工具栏。
- **移动端**：窄屏自动切成卡片式排列。

## 多设备同步（已下线）

> **当前状态：已下线。** 页面上不再出现「多设备同步」的入口，也不会发出任何网络请求；生词本、背诵、复习、导出 TXT、备份 JSON / 导入备份全部照常。下面的说明只是存档，方便以后想重新开启时参考。


默认所有数据只在本机浏览器。想让手机和电脑共用同一本生词本与背诵进度，用「同步码」——不用注册账号，一串码就是钥匙。538 与 179 共用同一串码、同一个生词本。

**一次性准备（约 10 分钟）**

1. 打开 [supabase.com](https://supabase.com) 注册（免费）→ New project，等它建好
2. 左侧 **SQL Editor** → 把仓库里的 `supabase-setup.sql` 全文粘进去 → Run
**在网页里开启（已内置配置，不用填地址和 key）**

3. 打开 `生词本.html` → 找到「多设备同步」。面板默认是锁着的，先输入**访问密码**解锁（密码由维护者保管，不写在页面里）
4. 点「生成新的同步码」，得到形如 `K7F3-9QW2-M4` 的一串码
5. 另一台设备打开同一页，输密码解锁后把码粘进输入框 → 点「用这个码」→ 两边自动合并

本仓库页面已内置一个免费的 Supabase 项目（项目地址与 publishable key 直接写在 HTML 里）。这个 key 属于「可公开」的类型，只被授权调用两个 `security definer` 函数，数据表本身对匿名用户完全不可读，放进页面没有安全风险；同步码是从 32 个字符里随机取 10 位（约 10^15 种组合），猜不到别人的码。

想换成**自己的** Supabase 项目：跑完上面第 2 步的 SQL 后，在已启用的面板里点「换配置」，填入你的 `Project URL` 和 `anon` / `publishable` key，再重新生成同步码即可（只影响本机，不改内置默认值）。

**行为说明**

- 四份词表页（表格版 / 例句版）与生词本页都会自动同步：改动后约 2 秒上传，打开页面或切到后台也会同步一次
- 合并规则：同一个词取「最后复习时间」较新的那条；每日统计按天取较大值
- 写入带版本校验，两台设备同时改也不会互相覆盖
- 关掉同步：点「停用」，本机数据保留
- 密码：输一次就记在本机（`sync-unlock`），不用反复输；点「锁定」可随时锁回去，锁定期间打开页面和自动上传都会暂停
- **码就是钥匙**：谁拿到码谁就能读写你的数据，别公开晒；数据只存在你自己的 Supabase 项目里
- 与真经站是两个独立仓库，同步码也各管各的（同一个 Supabase 项目里可以共用，因为数据按 `vj` / `kd` 分开存）

> **连不上怎么办**：如果面板提示「连不上 xxx.supabase.co」，而浏览器里直接打开那个网址显示 `ERR_CONNECTION_CLOSED` / 一直转圈，那是当前网络到 `supabase.co` 的连接被拦（国内很常见），不是密码或代码的问题。点面板上的「停用」即可回到纯本机使用，生词本和复习进度一条都不会少；跨设备搬数据改用生词本里的「备份 JSON / 导入备份」。

> 同步走的是 `https://` 接口，`file://` 双击打开时可能被浏览器的跨域策略挡住；建议用 GitHub Pages 地址或本地 `python3 -m http.server`。
