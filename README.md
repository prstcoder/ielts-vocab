# 雅思阅读 / 听力考点词 · 网页版

把两本雅思词汇 PDF（《剑桥雅思阅读考点词真经》538 词表、《剑桥雅思听力考点词真经》179 词表）整理成**可直接在浏览器里用的词表**：去掉了原 PDF 里的公众号水印、LOGO 和二维码，重新排版为表格与卡片，并为每个同义替换词补了中文释义、为每个词条补了中英例句。

直接用浏览器打开 `index.html` 即可，无需安装任何东西、不联网也完全可用。

## 页面

| 文件 | 说明 |
| --- | --- |
| `index.html` | 目录页，四份词表入口 |
| `雅思阅读538考点词.html` | 表格版：376 条考点词 + 523 个同义替换释义 |
| `雅思阅读538-例句版.html` | 卡片版：376 条，每词一句中英对照例句 |
| `雅思听力179考点词.html` | 表格版：179 条，含音标、词义 + 495 个同义替换释义 |
| `雅思听力179-例句版.html` | 卡片版：179 条，每词一句中英对照例句 |
| `生词本.html` | 生词本：538 与 179 共用一本，汇总 / 搜索 / 统计 / 闪卡 + 拼写 / 导出备份 |

## 功能

- **搜索**：中英文都能搜，单词、词义、同义替换、例句全文匹配；按 `/` 聚焦，`Esc` 清空。
- **默写模式**（例句版）：一键隐藏全部中文，只留英文，适合自测。
- **分项隐藏**：词义、替换词释义、例句译文可分别隐藏；表格版也有「隐藏词义 / 隐藏替换释义」两个开关。
- **状态记忆**：开关状态存在 localStorage，下次打开还是你上次的设置。
- **生词本**：四份词表里每条右侧都有 ☆，点一下收进同一本生词本（阅读 538 与听力 179 共用，便于把「考点词 + 同义替换」一起复习）。生词本页支持搜索、按来源/字母排序、导出 TXT、备份与导入 JSON。
- **背诵（逐词自测）**：每页右下角的「背诵这一页」是独立功能，跟生词本分开算。词卡一个一个跳出来，单词下面常显**纯英文例句**（表格版和例句版都有），先靠例句猜意思；点卡片（或空格）对答案，**释义 + 例句译文 + 同义替换 / 衍生词**一起出现。「不认识」就自动收进生词本并 10 分钟后重来，「认识」按 1→2→4→8→15→30→90 天往后推。538 和 179 各背各的，进度分别记录；「只背到期」可只过今天该复习的词。桌面端 `空格` / `1` / `2` / `Esc` 即可操作。弹层不受「默写模式」影响，开不开隐藏中文都能正常看答案。
- **遗忘曲线复习**：生词本按 `1·2·4·8·15·30·90` 天排期，答对升级、答错退回并 10 分钟后重来，连续答对 7 次记为「已掌握」。
- **拼写听写**：生词本里切到「拼写」模式，看中文释义（和同义替换）写英文，逐字判对错并显示正确拼写。
- **朗读**：单词和例句都能点小喇叭朗读（浏览器自带语音，优先英式发音）。
- **学习统计**：生词本页顶部有连续打卡天数、今日复习、今日新增、掌握率，以及近 14 天复习量柱状图。
- **打印友好**：`Cmd/Ctrl + P` 直接打印成纸质词表，不会带出工具栏。
- **移动端**：窄屏自动切成卡片式排列。

## 统计口径

- 阅读：376 个考点词（第 1 类 20 / 第 2 类 100 / 第 3 类 256），同义替换 523 处、去重 484 个，合计 899 条。
- 听力：179 个考点词，同义替换 495 处、去重 480 个，合计 674 条。
- 两份去重后共 536 个不同词条，全部配了中英例句。
- 原书标称的「538」= 376 个考点词 + 162 个红色标注的重点替换词；替换列里另有大量黑色补充词，全部算上是 523 个。
